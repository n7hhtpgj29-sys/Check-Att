อัปเกรดจาก v3 ที่กำลังใช้งานอยู่
================================

สำคัญ: Render Free ใช้ ephemeral filesystem ดังนั้น SQLite เดิมอาจหายตอน Deploy v6
ก่อนอัปเดต ควรเก็บไฟล์ Excel Employee Master ไว้

หลัง Deploy v6 ครั้งแรก:
1) เปิดแอป
2) ถ้า Total HC = 0 ให้ Upload Employee Master Excel อีก 1 ครั้ง
3) เปิด Master แล้วกด BACKUP TO IPHONE หรือกด Settings > Backup now
4) หลังจากนั้น v6 จะสำรอง Employee Master + Attendance state อัตโนมัติทุกครั้งหลัง Query สำเร็จ
5) ถ้า Render sleep/restart แอปจะ Restore state จาก iPhone อัตโนมัติ

ถ้าใช้ iPhone เครื่องใหม่ ให้ Export JSON จากเครื่องเดิม แล้ว Import JSON ในเครื่องใหม่
